# NetLab Protocol Specification

Files in this directory are **normative**. If documentation and an
implementation disagree with this directory, the specification wins.

Normative language uses **MUST**, **MUST NOT**, **SHOULD**, **SHOULD NOT** and
**MAY** in their usual requirements sense.

Start with:

1. `protocol.md`
2. `framing.md`
3. `messages.md`
4. `state-machine.md`
5. `errors.md`
6. `versioning.md`
