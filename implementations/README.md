# Implementations

Language implementations belong here and are intentionally not included in this
generated scaffold.

Suggested starting structure:

```text
implementations/
├── cpp/
│   ├── raw/
│   └── asio/
├── rust/
│   ├── std/
│   └── tokio/
└── go/
    ├── std/
    └── framework/
```

See `docs/guides/adding-a-language.md`.
